# Requisitos del Proyecto - Candelaria Shoes

**Modelo de Negocio:**
- Tienda especializada **exclusivamente** en sandalias para mujer (zapatillas típicas colombianas).
- No hay otras categorías de productos.
- Enfoque en comodidad, estilo fresco, boho-chic y tropical colombiano.

**Páginas del Cliente (Frontend):**
- Home impactante
- Shop (grid de sandalias con filtros)
- Detalle de producto
- Carrito
- Checkout simulado

**Sección Admin (Dashboard sencillo):**
- Ruta protegida (/admin)
- Formulario para agregar nuevas sandalias (nombre, descripción, precio, tallas disponibles, colores, imágenes)
- Lista de productos con opción de editar/eliminar
- Dashboard básico de ventas (visualización simple de órdenes simuladas)
- Gestión básica de inventario

**Funcionalidades Técnicas:**
- Productos dinámicos (se guardan en localStorage o archivo JSON por ahora)
- Filtros en Shop: por precio, talla, color
- Carrito persistente
- Admin simple pero funcional
